### Description

In my third year of my bachelor’s degree, I had the opportunity to undertake an optional summer internship at the CNRS LIRIS laboratory.
The aim of this project was to create a proof of concept utilising the five touch-sensitive walls in the Ark room at INSEEC Chambéry, with the goal of collaborative and computer-assisted learning, following the **B**ring **Y**our **O**wn **D**evice approach.

This POC was developed using the Godot game engine, a smartwatch running Wear OS, and a Python scheduler.

We developed the following features:
- Representation of students as avatars moving around a map.
- Tools for lecturers to create adaptive questionnaires that adjust based on responses
- A smartwatch app enabling users to modify course content, send documents, and send widgets such as a wheel of fortune, dice, timers, etc.
- Creation of a scheduler to manage questionnaires in parallel

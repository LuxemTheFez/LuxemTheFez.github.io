### Description
The last year of my master's degree could be done in apprenticeship. After my internship, I chose to continue at **Orange Cyberdefense** to deepen my knowledge and skills. During my apprenticeship, I had the opportunity to perform the following tasks, some of which were a continuation of the work I did during my internship:

- Creation of a front-end template/toolkit using Vue 3 & Vuetify, using Orange Cyberdéfense’s design system, to serve as the basis for all future projects within the department
- Contributing to the support, debugging and improvement of the in-house microsoc software
- Creation of an internal tool using Laravel 10 and Vue 3 enabling:
    - Reporting bugs, where other users could provide further details in the comment of the issue encountered
    - Creating releases notes
    - Creating roadmaps, to which users can respond and add comments
- Project management:
    - Benchmarking the version upgrade of the internal stack and researching new frameworks to be used in future projects
    - Code review of an intern who joined the project
    - Pull request review and management on the new project
    - Task allocation
- Creating mock-ups using Figma for the various in-house tools
- Setting up and configuring development and pre-production servers
- Managing application deployment using Docker and Docker Compose
- Retrieving and generating dummy API data for the creation of non-regression tests
- Creating automated end-to-end and non-regression tests using DataDog

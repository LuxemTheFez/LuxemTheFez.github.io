### Description
Je suis actuellement en CDI dans la société **GO2cam International**. J'occupe un poste d'ingénieur R&D, plus spécifiquement, je suis tech lead sur une nouvelle application FAO web en cours de développement. Mes principales missions sont :

- Améliorer le moteur C++ géométrique 2D/3D interne de GO2cam
- Implémentation de calculs côté client via du WebAssembly pour améliorer les performances et tirer parti de notre moteur géométrique interne existant
- Implémentation de l'api et création des schémas de la base de données
- Utilisation de ThreeJS comme moteur de rendu en complément du moteur géométrique WASM

J'ai aussi des tâches annexes, comme de la gestion de projet, de la revue de code sur les autres projets web du service ainsi que le mise à jour de la pipeline CI/CD desdites applications. Enfin, j'occupe aussi un rôle de sysadmin pour la preprod et le server de production, en plus d'être le backup du manager IT.

### Description
Following my previous internship, researchers Mr Jean-Charles Marty and Mr Thibault Carron invited me and two friends to continue working with them but this time on a new proof-of-concept project for collaborative learning.
The aim here was to recreate a sort of modern Moodle clone but with the collaborative features that it lacks.

As part of this project, I carried out the following tasks:
- Creating a Python API using Flask and Flask Restful
- Connecting the Python backend to the MongoDB database and creating models with flask-mongoengine
- Creating a collaborative whiteboard using VueJS and a WebSocket connection
- Creating a teacher interface so that they can create their lessons and quizzes
- Creating the student section where they can take quizzes, either individually or in groups, or read lessons and documents

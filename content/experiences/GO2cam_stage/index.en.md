### Description
As part of my second Master’s degree, specialising in video game and 3D engineering, I was required to undertake an internship. I chose to carry this out at **GO2cam International**, where I was able to contribute to the development of version 2026 of the 3D CAD/CAM software **GO2cam**. I was responsible for the following tasks:

- Helping to refactor the software’s graphics engine, based on **OpenGL**
- Creating Qt interfaces to replace older interfaces that were rendered via OpenGL
- Rewriting the 3D preview to incorporate the new features implemented in the graphics engine refactoring
- Implementing a threading system for loading large 3D files, to improve performance and reduce crashes
- Enhancing an older OpenGL interface within a Qt OpenGL container to enable additional features and a better user experience
